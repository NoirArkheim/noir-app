# Нуар-мафия — утренний выпуск

Просмотрщик выпуска-комикса для телефона (позже — мини-приложение Telegram).
Простая страница без сборки: подходит для GitHub Pages.

## Как посмотреть у себя

Двойной щелчок по файлу «Открыть выпуск.command». Откроется браузер.
Чтобы остановить, закройте окно Терминала.

Управление: тап или свайп влево — дальше (во время панорамы — сразу
к кадру комикса), свайп вправо — назад, сразу в виде кадра комикса.
На компьютере: клик, стрелки ← →, пробел.

## Файлы

- `issue.json` — список слайдов и подписи. Тексты подписей меняются только здесь.
  - `image` — картинка, `caption` — подпись (пустая строка — без подписи,
    `\n` — перенос строки), `title` — название кадра для себя.
  - Горизонтальные кадры показываются в два этапа: сначала панорама во всю
    высоту экрана слева направо (7 секунд), потом кадр уменьшается до кадра
    комикса в рамке, под ним — подпись. Если главное в кадре справа,
    добавьте слайду `"pan": "right-left"` — камера пойдёт справа налево.
  - Новый выпуск: скопируйте файл, например в `issue-2.json`, и откройте
    `index.html?issue=issue-2.json`.
- `art/splash/`, `art/panels/` — исходные PNG (копии из `noir_art`). В git и на сайт
  не попадают (см. `.gitignore`), лежат только на этом компьютере.
- `art/web/` — сжатые webp для телефона. Их и показывает страница.
- `index.html`, `style.css`, `viewer.js` — сам просмотрщик.
- `telegram.js` — связь с Telegram. Без Telegram страница работает так же.

## Как сделать webp из нового PNG

Вертикальная картинка (заставка) — ширина до 1080:

    cwebp -q 80 -resize 1080 0 art/splash/имя.png -o art/web/имя.webp

Горизонтальный кадр — в полном размере (на телефоне он растянут
на всю высоту экрана, уменьшать его нельзя, иначе станет мыльным):

    cwebp -q 80 art/panels/имя.png -o art/web/имя.webp

## Карта города

`map.html` — карта Нью-Аркхейма. Открыть из Telegram сразу на карте:
ссылка `https://t.me/NewArkheimBot?startapp=map`.

- `map.json` — всё, что рисуется поверх картинки: районы и их цвета,
  кварталы, постоянные точки и заведения сета (`venues`). Заведения меняются
  каждый сет — перед сетом поправьте список `venues` (квартал, тип, название).
  Цвет района `""` — без подсветки.
- `columns` и `rows` — где на картинке лежат кварталы (в пикселях исходной
  картинки 1024×1536). Менять, только если поменяется рисунок карты.
- Кнопки внизу включают и выключают подсветку районов и метки,
  «＋» вверху приближает карту вдвое. Нажатие на квартал — карточка с тем, что в нём есть.
