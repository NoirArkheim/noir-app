# Нуар-мафия — утренний выпуск

Просмотрщик выпуска-комикса для телефона (позже — мини-приложение Telegram).
Простая страница без сборки: подходит для GitHub Pages.

## Как посмотреть у себя

Двойной щелчок по файлу «Открыть выпуск.command». Откроется браузер.
Чтобы остановить, закройте окно Терминала.

Управление: тап или свайп влево — дальше, свайп вправо — назад.
На компьютере: клик, стрелки ← →, пробел.

## Файлы

- `issue.json` — список слайдов и подписи. Тексты подписей меняются только здесь.
  - `image` — картинка, `caption` — подпись (пустая строка — без подписи,
    `\n` — перенос строки), `title` — название кадра для себя.
  - Горизонтальные кадры показываются во всю высоту экрана с панорамой
    слева направо (7 секунд). Если главное в кадре справа, добавьте слайду
    `"pan": "right-left"` — камера пойдёт справа налево.
  - Новый выпуск: скопируйте файл, например в `issue-2.json`, и откройте
    `index.html?issue=issue-2.json`.
- `art/splash/`, `art/panels/` — исходные PNG (копии из `noir_art`).
- `art/web/` — сжатые webp для телефона. Их и показывает страница.
- `index.html`, `style.css`, `viewer.js` — сам просмотрщик.
- `telegram.js` — связь с Telegram. Без Telegram страница работает так же.

## Как сделать webp из нового PNG

Вертикальная картинка (заставка) — ширина до 1080:

    cwebp -q 80 -resize 1080 0 art/splash/имя.png -o art/web/имя.webp

Горизонтальный кадр — в полном размере (на телефоне он растянут
на всю высоту экрана, уменьшать его нельзя, иначе станет мыльным):

    cwebp -q 80 art/panels/имя.png -o art/web/имя.webp
